Доступна [глава «Бюджет Вселенной»](chapters/01-budget-of-the-universe.md), полный перевод главы The Budget of the Universe из английской ревизии `e39402c05fe22473009cb1e6bb57097a9ab42680`. Остальные главы здесь пока не переведены. Это частичная русская редакция.

Отдельные двуязычные материалы по моделированию уже находятся в репозитории:

- [Диффузия и потребление кислорода](../../courses/oxygen-diffusion/README.md), [русские материалы](../../courses/oxygen-diffusion/ru/README.md).
- [Адвекция, дисперсия и потеря исходного вещества](../../courses/advection-dispersion/README.md), [русские материалы](../../courses/advection-dispersion/ru/README.md).

Приложение D (Math Without Pain), на которое ссылается глава, доступно [на английском](../../appendices/d-math-without-pain.md).

Эти маршруты относятся к полному репозиторию. Исходный пакет этой главы не дублирует существующие учебные модули. Перевод соответствует исправленной и проверенной английской главе. Это не научная приёмка остальных глав книги. Сборку и визуальную проверку готовых форматов выполняют отдельно.

## Локальная сборка главы

Из корня репозитория:

```sh
python3 translations/ru/build-chapter01.py --output /tmp/book-chapter01-ru
```

Нужны Quarto, XeLaTeX, шрифты PT Serif и PT Sans и русские шаблоны переносов TeX. В TeX Live и TinyTeX их устанавливает `tlmgr install hyphen-russian`. После установки нужно заново собрать PDF; без этих шаблонов длинные русские слова могут выходить за правое поле. Каждый запуск создаёт новую папку вне репозитория. Параметр `--to html`, `--to pdf` или `--to epub` выбирает один формат; без него собираются все три. Путь к Quarto можно указать через `--quarto`.

Исходники копируются в папку сборки. В PDF врезки оформляются как отступ с заголовком, чтобы сноски сохраняли свои номера. HTML и EPUB сохраняют оформление врезок.
