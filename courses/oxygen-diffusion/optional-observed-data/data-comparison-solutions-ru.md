# Сравнение с измерениями: решения

Соответствует `data-comparison-solutions.md` v1. Решения открыто доступны в материалах книги. Сначала попробуйте выполнить задание самостоятельно.

1. Статья связывает запись 12536642, v1. На дату проверки последняя запись: 15367775, v2 от 8 мая 2025 года. MD5: v1 `3aa0ff04a92467b2ebcbeba730d47d09`, v2 `80aeb327b8ebecd9d359c1c1b5ba0e00`. Файлы различаются.
2. C6, июль 2019 года: v1 DOU = 10,281, TOU = 22,69 ммоль/(м² · сутки), глубина = 3,75 мм. V2 DOU = 7,26378779, TOU = 25,12771396, глубина = 3,0 мм. Отношение v2 = 0,289074756. DOU оценивают по диффузионному градиенту, TOU по потреблению в камере. Методы и охватываемые процессы различаются.
3. Учебный поток = 1,37556369 ммоль/(м² · сутки). Параметры учебной модели не измерены на этой станции. Поверхностная концентрация, нижняя граница и пространственно постоянный k выбраны условно. Это описание различия условий, а не независимая проверка прогноза или калибровка.
4. Среднее семи отношений в архивной v2 = 0,292795523. Отношение сумм = 0,283052007. Первое одинаково взвешивает станции, второе взвешивает по TOU. В статье указан итог 0,33 ± 0,07. Это нельзя объявить ошибкой округления. Раздел 4.1 описывает поправку 2,3 ммоль/(м² · сутки), полученную из более ранней оценки дыхания воды. В расчётах пакета эта поправка повторно не применяется. Полное согласование всех строк с публикацией остаётся открытым. B5 2019 исключается из отношений из-за отсутствия DOU, но сохраняется в исходных данных.
5. Нужны калиброванные профили с неопределённостями, положение поверхности, температура, солёность, пористость, независимо ограниченный Dₛ, граничные концентрации, проверка течения и обмена через норы, предел обнаружения и обоснование нижней границы. Сначала оценивается α = k/Dₛ. Для независимой проверки можно использовать другие керны или отдельное изменение граничной концентрации с временными профилями и потоками. Параметры при проверке заново не подгоняют. Для разделения кислородных стоков нужны дополнительные химические или биологические наблюдения.

Критерии, 10 баллов: версия и контрольные суммы (2), строка и единицы с правильным отношением (2), соответствие наблюдаемой величины и ограничение условных параметров (2), различие способов усреднения и поправки без искусственного согласования (2), идентифицируемость и независимая проверка (2). Синтетические данные нельзя называть полевыми измерениями.
