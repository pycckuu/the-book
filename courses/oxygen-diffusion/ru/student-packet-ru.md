## Принятая учебная модель

Глубина x возрастает вниз от границы между осадком и водой. C есть количество растворённого кислорода на единицу объёма поровой воды, в mol m^-3 water. Пористость phi безразмерна. D_s есть коэффициент диффузии в осадке с поправкой на извилистость, в m2/s; дополнительный множитель пористости в его определение не входит. F есть поток на единицу площади осадка, положительный вниз. q = kC есть потребление кислорода на единицу объёма поровой воды. R = -phi q есть источник кислорода на единицу объёма осадка, отрицательный при потреблении.

Уравнение O2-Q01, баланс на единицу объёма осадка:

$$\frac{\partial(\phi C)}{\partial t}=-\frac{\partial F}{\partial x}-\phi kC,\qquad F=-\phi D_s\frac{\partial C}{\partial x}.$$

При постоянных phi > 0, D_s и k, отсутствии адвекции и явно описанной биологической адаптации уравнение O2-Q02 имеет вид

$$\frac{\partial C}{\partial t}=D_s\frac{\partial^2 C}{\partial x^2}-kC.$$

Область: 0 < x < L. Условия: C(0,t) = C_0 при t > 0; dC/dx(L,t) = 0; C(x,0) = 0 внутри области. Верхняя граница включается при t = 0. Возникающий на ней разрыв задан намеренно. Нижнее условие замыкает модельную область; оно не утверждает, что любой осадок имеет непроницаемую нижнюю границу.

Потребление первого порядка описывает суммарное потребление кислорода. Оно не отличает аэробное дыхание с окислением органического углерода от окисления восстановленных химических компонентов. В базовую модель не входят термодинамический множитель, динамика донора, связь сульфата и метана, переменная пористость, адвекция, ирригация и многомерная геометрия.

Уравнение O2-Q03, эталонное стационарное решение (k > 0):

$$C_{ss}(x)=C_0\frac{\cosh((L-x)/\ell)}{\cosh(L/\ell)},\qquad \ell=\sqrt{D_s/k}.$$

При положительном C_0 решение остаётся положительным. Практически определяемая глубина обнаружения есть пересечение порога, а не точная граница отсутствия кислорода. Для количественных ответов используйте формулы конечной области. Экспонента C_0 exp(-x/ell) есть лишь приближение у поверхности для глубокой области.

Все входные значения ниже выбраны для иллюстрации; это не полевые измерения и не значения, откалиброванные по литературе.

| Вход | Значение | Смысл |
|---|---:|---|
| L | 0.03 m | Глубина области |
| D_s (в коде `D`) | 1e-9 m2/s | Коэффициент диффузии без множителя пористости |
| k | 1e-5 s^-1 | Коэффициент суммарного потребления первого порядка |
| phi | 0.8 | Пористость, заполненная водой |
| C_0 | 0.2 mol/m3 water (200 micromol/L) | Концентрация на границе |
| N, dt | 80 ячеек, 1000 s | Базовые настройки нестационарного расчёта |

В коде используйте `D` для математического D_s. Для сравнения областей в E04 фиксированная глубина оценки равна x = ell_baseline = 0.01 m, а короткая область имеет L = 0.01 m. В остальных случаях используется исходное L, если не указано иное.
