# Кислород: модуль 1.0

[Задания студенту](student-packet-ru.md), [учебная программа](curriculum-ru.md), [методы проверки](verification-methods.md), [глава 8](chapters/08-the-equation.ru.md), [приложение B](appendices/b-model-toolkit.ru.md), [двуязычный глоссарий](../glossary-bilingual.tsv).

[Решения и критерии оценивания](instructor-packet-ru.md) открыты для всех читателей. Сначала попробуйте выполнить задания самостоятельно. [Протокол учебного пилота](pilot-protocol-ru.md) подготовлен, но ещё не выполнен.

Из этого каталога выполните `python3 model/oxygen_model.py --out my-run`. Без Python используйте архивные результаты по указаниям студенческого пакета. Для преподавательской проверки перейдите в `../en/` и выполните `python3 check_teaching.py`: обе версии используют один код и одинаковые численные ответы.

Студентам передавайте задания, программу, методы проверки, ссылки, каталоги `data/` и `model/`, русские главу и приложение, схематический рисунок `sources/img/ch8_porewater_profile.png` и глоссарий. Библиография находится в основном каталоге книги `../../../sources/bibliograph.bib`; сохраняйте относительные пути этих материалов или выдавайте готовый студенческий архив. Решения, заполненные таблицы чувствительности и невязок, а также проверочный скрипт доступны открыто. Студенческий пакет помогает сначала выполнить задания самостоятельно, но не ограничивает доступ к ответам.
