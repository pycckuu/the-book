# Методы верификации для студентов

В проверенной численной модели используются метод конечных объёмов с концентрациями в центрах ячеек и неявный метод Эйлера. В коде `D` означает D_s. Концентрации отчёта относятся к центрам ячеек, а не границам ячеек. На фиксированной верхней границе используется половина ширины ячейки, снизу задан нулевой поток.

Пространственная проверка напрямую решает дискретную стационарную задачу при N = 20,40,80,160 и сравнивает значения в центрах с непрерывным аналитическим стационарным решением. Допустимый порядок: от 1.8 до 2.2. Ошибки установления состояния за конечное время здесь нет.

Отдельная временная проверка использует N = 100 и гладкое начальное состояние: дискретная стационарная концентрация плюс 0.02 sin(pi x/(2L)). Она сравнивает результат с точной полудискретной собственной модой при t = 20000 s и dt = 1000,500,250,125 s. Допустимый порядок: от 0.95 до 1.05. Непрерывный эталон при фиксированном N также включает пространственную ошибку. Это отличается от начального заполнения с нулевой концентрацией внутри области и скачком на границе; разрыв в точке включения верхнего граничного условия не используется для установления гладкого порядка по времени.

Проверки охватывают однородное стационарное решение k = 0, чистый распад D_s = 0, пределы малого k и глубокой области, масштабирование поверхностного значения, инвариантность при совместном масштабировании D_s/k и отклонение некорректных входов. Мгновенная невязка дискретного баланса кислорода должна быть меньше 1e-17 mol/m2/s, накопленная невязка начального заполнения меньше 1e-13 mol/m2. Неотрицательность проверяется без обрезания; концентрации при начальном заполнении не должны превышать C_0 + 1e-14. Для сравнений пределов в исходнике заданы свои допуски. Одна устойчивость не проверяет точность.

Все учебные входы и наблюдения для подбора параметра синтетические. Численная верификация не является проверкой по эмпирическим данным. Код печатает эталон подбора; в E05 студенты всё равно должны восстановить его целевую функцию, невязки и ограничения вывода.
