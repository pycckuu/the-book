# Двуязычный глоссарий модуля кислорода

Глоссарий содержит 53 термина с согласованными научными определениями и учебным употреблением. Ограничения указаны в каждой строке. TED в формулах и коде сохранён.

| English | Русский | Определение и употребление |
| --- | --- | --- |
| porewater | поровая вода | Вода в порах осадка; концентрация C относится к объёму этой воды. |
| porewater concentration | концентрация в поровой воде | Количество компонента на единицу объёма поровой воды, C. |
| bulk concentration | концентрация на единицу объёма осадка | Количество компонента на единицу полного объёма осадка, включая твёрдую фазу и поры; для растворённого компонента равно phi C. |
| sediment-water interface | граница между осадком и водой | Поверхность, от которой отсчитывается глубина осадка; глубина возрастает вниз. |
| porosity | пористость | Доля полного объёма насыщенного осадка, занятая поровой водой; безразмерна. |
| tortuosity | извилистость порового пространства | Геометрическое свойство извилистых путей в порах. Конкретную поправку задаёт модель; нельзя автоматически выбирать квадрат или первую степень. |
| effective diffusion coefficient in sediment | эффективный коэффициент диффузии в осадке | D_s [m2/s] учитывает извилистость порового пространства, но не пористость: F = -phi D_s C_x. При другом соглашении D_eff = phi D_s второй множитель phi в потоке не нужен. Эти определения нельзя смешивать. |
| molecular diffusion | молекулярная диффузия | Перенос растворённого вещества в сторону уменьшения концентрации в рассматриваемом приближении. |
| advection | адвекция | Перенос вместе с движущейся средой; u есть скорость поровой воды, а не расход Дарси на единицу площади. |
| flux | поток | Количество вещества, проходящее через единицу площади за единицу времени. Обозначение F сохраняется. |
| flux divergence | дивергенция потока | В одном измерении дивергенция равна dF/dx. В баланс входит отрицательная дивергенция -dF/dx, чистый приток на единицу полного объёма осадка. |
| accumulation | накопление | Изменение количества вещества на единицу объёма осадка со временем; может быть положительным или отрицательным. |
| reaction-transport model | модель переноса с реакциями | Связанная система балансов, законов переноса и скоростей реакций. |
| reaction-diffusion model | модель диффузии с реакциями | Частный случай модели переноса с реакциями без адвекции. |
| steady state | стационарное состояние | Состояние без изменения во времени в указанной системе отсчёта; не означает термодинамического равновесия. |
| thermodynamic equilibrium | термодинамическое равновесие | Для указанной реакции Delta G = 0. При сопряжённом дыхании с сохранением энергии в АТФ движущая сила равна нулю при f = -Delta G_r - m Delta G_p = 0. Это не то же условие, что Delta G_r = 0 для окислительно-восстановительной реакции. |
| boundary condition | граничное условие | Условие на границе модельной области. Нужно сохранять её положение и тип условия: концентрация или поток. |
| initial condition | начальное условие | Состояние системы в момент начала расчёта, зависящего от времени. |
| oxygen consumption | потребление кислорода | Потребление кислорода. Положительная величина потребления входит в баланс кислорода со знаком минус. |
| oxygen penetration depth | глубина проникновения кислорода | Глубина, определённая по указанному порогу обнаружения кислорода. Экспоненциальный хвост не имеет точного конечного нуля. |
| first-order consumption | потребление по кинетике первого порядка | Потребление со скоростью, пропорциональной C. В пилотной модели k имеет размерность обратного времени. |
| zero-order consumption | потребление по кинетике нулевого порядка | Постоянная скорость потребления в указанной области применимости. Модель должна исключать отрицательные концентрации. |
| half-saturation constant | константа полунасыщения | Константа K_m имеет те же единицы и основу объёма, что концентрация соответствующего субстрата. |
| Michaelis-Menten kinetics | кинетика Михаэлиса и Ментен | Выражение насыщения по одному субстрату с обозначениями V_max, S и K_m. |
| dual-Monod kinetics | кинетика Моно с двумя лимитирующими субстратами | Произведение факторов насыщения по донору и акцептору; не означает две отдельные реакции. |
| terminal electron donor | донор электронов | В новом тексте используется «донор электронов», без слова «конечный». Слово «конечный» относится к соглашению об акцепторе. TED сохраняется как прежний идентификатор в формулах и коде; уточнение внесено в утверждённый английский источник R2. |
| terminal electron acceptor | конечный акцептор электронов | Конечный акцептор электронов; аббревиатура TEA сохраняется в формулах и коде. |
| thermodynamic factor | термодинамический множитель | F_T относится к конкретной энергетической модели. В учебной модели кислорода его нет. Логистическая эвристика не обеспечивает нулевую суммарную скорость при равновесии; используется утверждённая замена в приложении B. |
| yield | выход биомассы | Для биомассы: выход биомассы. Для энергии: выход энергии. Единицы задаются отдельно. |
| early diagenesis | ранний диагенез | Преобразования в осадке после осаждения, рассматриваемые в книге. |
| sulfate reduction | сульфатредукция | Восстановление сульфата; выполняющие его организмы называются сульфатредуцирующими. |
| sulfate-methane transition | сульфат-метановый переход | Зона взаимодействия поступающего сульфата и метана. Её нельзя определять по равенству кривых в разных относительных шкалах. SMT сохраняется. |
| anaerobic oxidation of methane | анаэробное окисление метана | Анаэробное окисление метана; аббревиатура AOM сохраняется для сопоставления языковых версий. |
| dissolved inorganic carbon | растворённый неорганический углерод | Растворённый неорганический углерод, DIC. Не путать с растворённым органическим углеродом. |
| syntrophy | синтрофия | Метаболическая взаимозависимость организмов; более точное понятие, чем общее сотрудничество. |
| effective parameter | эффективный параметр | Параметр, объединяющий несколько механизмов на указанном масштабе усреднения; не универсальное свойство фермента. |
| representative elementary volume | представительный элементарный объём | Объём усреднения при описании сплошной среды; REV сохраняется, если используется в исходнике. |
| closure term / relation | замыкающий член / замыкающее соотношение | Дополнительный член или соотношение, описывающее процессы, не разрешённые явно в модели. |
| verification | верификация | Проверка правильности решения заданных уравнений, например по аналитическому решению и сходимости. Не проверка соответствия природе. |
| validation | проверка по независимым данным | Проверка прогнозов по независимым наблюдениям в указанных условиях; после определения допустимо слово валидация. |
| calibration | калибровка | Подбор параметров по калибровочным данным; не независимая проверка модели. |
| identifiability | идентифицируемость | Возможность однозначно определить параметры по указанным данным при заданной модели. |
| sensitivity | чувствительность | Изменение результата при заданном изменении входного значения или параметра. |
| uncertainty | неопределённость | Неопределённость входных данных, параметров или структуры модели; не обязательно доверительный интервал. |
| schematic / illustrative | схематический / иллюстративный | Учебная схема, а не измеренные данные и не свидетельство проверки модели по наблюдениям. |
| satisficing | поиск достаточно хорошего решения | Поиск решения, достаточного при данных ограничениях. Концептуальная перспектива, а не заданная здесь целевая функция. |
| rubric | критерии оценивания | Критерии оценивания; IDs, веса и суммарные баллы сохраняются. |
| reference solution | эталонное решение | Решение для преподавателя, отделённое от студенческого пакета; исполняемый код сохраняется. |
| diffusive oxygen uptake (DOU) | диффузионное поглощение кислорода (DOU) | Направленный внутрь осадка поток кислорода, рассчитанный по разрешённому диффузионному градиенту с соглашениями исследования о коэффициенте и площади; поглощение считается положительным. Не определяет единственный механизм потребления. |
| total oxygen uptake (TOU) | суммарное поглощение кислорода (TOU) | Поглощение кислорода в камере при заданных соглашениях о площади, времени и поправке на водную толщу; может включать дополнительные пути переноса и потребления. Архивные поправки отдельно не сверены. |
| aggregate oxygen demand | суммарное потребление кислорода | Эффективное суммарное потребление, которое может включать биологическое дыхание и окисление восстановленных соединений. Для разделения механизмов нужны дополнительные данные. |
| structural non-identifiability | структурная неидентифицируемость | Стационарный профиль ограничивает alpha = k/Ds, но не позволяет независимо определить Ds и k без дополнительного ограничения. |
| parametric bootstrap | параметрический бутстреп | Повторные синтетические выборки при заданной модели и законе ошибки; оценивают условную неопределённость и не подтверждают модель полевыми данными. |
