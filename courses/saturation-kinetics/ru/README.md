[Учебный план](curriculum.md), [карта результатов](exercise-outcome-map.json) и протокол ещё не проведённого [учебного пилота](pilot-protocol.md) описывают пять заданий, 100 баллов и 210 планируемых минут плюс необязательное 15-минутное повторение. ## Предоставленные файлы

[README модели](../model/README.md) и [ZIP сохранённых результатов](../model/saved-results.zip) сопровождают каждый учебный комплект. Распакуйте ZIP в новую пустую папку. Имена внутри него имеют префикс `results/`: метаданные случаев находятся в `results/case-manifest.json`, временные срезы low/high в `results/low-snapshots.csv` и `results/high-snapshots.csv`, полные журналы обновлений в `results/low-step-ledger.csv` и `results/high-step-ledger.csv`. Ссылки на входные файлы, имеющиеся только в архиве, открывают ZIP, а не отдельные CSV. Таблицы временных срезов содержат 401 фиксированный момент для каждого случая. Таблицы переходного и вспомогательных случаев поддерживают верификацию владельца; они не добавляют студентам заданий.

Непосредственно доступны компактные файлы [кривой скорости](../model/results/rate-curve.csv), [порогов](../model/results/thresholds.csv) и [уточнения шага](../model/results/time-refinement.csv). Локальные [пустой рабочий лист](worksheets/blank-step-worksheet.csv) и [открытые рассчитанные значения](worksheets/OPEN-worked-step-values.csv) сохраняют предоставленные байты. Обязательны только строки шагов 1 и 2 случая low. О контекстных фрагментах прочитайте в [зависимостях от книги](DEPENDENCIES.md). Все данные модели синтетические.

## Маршрут с готовыми результатами в электронной таблице

Импортируйте CSV в UTF-8 с запятыми как разделителями, сохраняя заголовки и точность чисел. Пустые ячейки означают null/неопределённое/недоступное значение согласно описанию владельца, никогда не ноль. Первые две строки данных рабочего листа low содержат $S_n$, $S_{n+1}$, $q_{n+1}$ и фактическое $h$; восстановите

$$
\Delta Z=hq_{n+1},\quad \Delta B=V_\ell\Delta Z,\quad
B_n=\sum_{i=1}^n\Delta B_i,\quad M_n=V_\ell S_n.
$$

Сохраняйте $V_\ell=0.001\,\mathrm{m^3}$. В этом рабочем листе владельца задайте ячейке `T1` значение `0.001`. Для строки 2 используйте `J2=F2*I2`, `K2=SUM($J$2:J2)`, `L2=$T$1*H2`, `M2=$T$1*J2`, `N2=SUM($M$2:M2)`, `P2=L2+M2-$T$1*G2`, `Q2=L2+N2-O2`, `R2=H2+J2-G2`. Скопируйте только в строку 3 для второго назначенного шага low. Эти буквы столбцов относятся к локальному **пустому рабочему листу со столбцом случая**, а не к полному журналу с другой структурой. README модели предоставляет другую вспомогательную структуру для полного журнала. Не смешивайте две структуры.

Не копируйте формулы накопленной суммы `SUM` через более поздние несмежные строки/смены случаев в рабочем листе. Для этих накопленных значений нужны все промежуточные приращения из соответствующего полного журнала, а не сумма выбранных строк. Для полного журнала low используйте вспомогательные столбцы, документированные владельцем в его [неизменённом README](../model/README.md). Интерполяция временных срезов не добавляет шагов баланса. В отчёте укажите анализ предоставленных результатов.

## Канонический маршрут с Python

Из `courses/saturation-kinetics/ru/`:

```sh
cd ../model
python3 saturation.py new-results
```

Используйте новую пустую папку результатов. Нужна только стандартная библиотека Python; `saturation.py` требует соседний `pre-run-plan.json`, соответствующий текущему коду в комплекте. Необязательная команда `python3 check_saved_csv.py new-results` восстанавливает экспортированную арифметику без импорта/запуска решателя. Выполнение всех случаев владельца не добавляет студентам заданий по переходному/вспомогательным случаям. Учебные материалы используют предоставленные верифицированные результаты. Для `saturation.py` нужен обычный Python без `-O`/`-OO` и с удалённой из окружения `PYTHONOPTIMIZE`. Код и план прежнего расчёта остаются историческими.
