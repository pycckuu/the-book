# Spreadsheet or manual readback of supplied results

Analyse supplied outputs and state that route explicitly. It reproduces calculations from a pinned solve; it is not an independent solver run. See case-manifest.json and model-interface.md before calculations. Both exercises and answers may be openly available; keep a first attempt separate from answer consultation.

1. In one case's pulse-budget CSV, compute dt=t_right_s-t_left_s. Calculate delta_I=dt*F_in_interval_average and delta_O=dt*F_out_right_endpoint. Calculate delta_B=dt*k*M_next using that case's k. Compare with supplied increments.
2. Compute M_next-M_previous-delta_I+delta_O+delta_B per row. Cumulate I/O/B from the first row, retaining initial storage. Check M_next-M_initial-I+O+B. Do not replace right-endpoint loss/export with trapezoidal integration.
3. Independently compute snapshot storage by summing phi*(x_right-x_left)*C_cell_average from profiles. Compare with the step ledger at that exact time. Reconstruct internal face advection and dispersion from adjacent cell averages; use the separately documented inlet trace only for diagnostic components. Check component sums and equal/opposite slab faces.
4. Plot outlet concentration against the declared right-endpoint times. Find the maximum and its earliest sampled time. For quantiles, divide cumulative O by the final O of that window; interpolate linearly within the interval containing 0.1,0.5,0.9. Label these as conditional on exported mass. For time moments use each delta_O and exact uniform-interval time moments stated in scientific-teaching-alignment.md in contract-and-evidence. Spatial width is a separate profile statistic with h^2/12.
5. Recompute absolute/refined metric changes and tolerance columns in independent-refinement.csv. Calculate observed order as log(error_coarse/error_fine)/log(2) in steady-spatial.csv or periodic-time.csv, grouping the correct fixed controls. A conserved curve can still be inaccurate or too broad. Periodic and hyperbolic checks have auxiliary boundary problems.
6. For synthetic interval observations, use truth_refined-synthetic-source-series.csv. In each row calculate overlap=max(0,min(observation_right,step_right)-max(observation_left,step_left)). Sum overlap*C_out_right_endpoint and divide by observation duration. Apply the same formula to each k0/k1/k2 source series; compare prediction minus observation, then RMSE in the original concentration units. Do not normalize to the peak or invent sigma.

The synthetic source grid is finer than the candidate grid. A matching-k score is therefore small but nonzero. Neither selecting that candidate nor reassembling a ledger establishes aquifer validity, practical multi-parameter identifiability or a unique reaction mechanism. Remaining inventory and aggregate disappeared parent must be reported.
