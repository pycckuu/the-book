## Проверенные численные входные данные

Фиксированный шаг $100\,\mathrm{s}$ принят для этой ограниченной синтетической модели. Фактический провал по точности при $400\,\mathrm{s}$ и проход при $200\,\mathrm{s}$ сохранены; не утверждается, что значение по умолчанию является самым грубым проходящим шагом. CSV используют UTF-8, запятые как разделители, десятичные точки и 17 значащих цифр; пустые ячейки означают null там, где это явно указано причиной. Все выходные данные имеют `synthetic=true`. Измеренные наблюдения не предоставлены. Собственная идентичность журнала равна `(case_id,run_id,time_s)`, а идентичность сравнения равна `(case_id,run_id,support_id,time_s,quantity)`. Не сравнивайте неравные моменты времени и не объединяйте суммы разных случаев и прогонов.

Для E04 локальные HTML-представления используют точные поля `forward:100s` в моменты $t=0,100,200\,\mathrm{s}$. Скопируйте таблицу полей в электронную таблицу A1:D19. Следуйте её указаниям по вспомогательным ячейкам и формулам только для столбцов C и D. Устойчивые значения энергии Гиббса и мощности предоставлены; их устойчивая нелинейная реализация не является заданием. Полный архив таблиц остаётся доступным для происхождения данных; полные массивы и дополнительная вспомогательная реконструкция не обязательны.

## Единицы, носители и null

$c_i$ измеряется в $\mathrm{mol\,m^{-3}}$ жидкости, $n_i=V_\ell c_i$ в $\mathrm{mol}$ эквивалента; $r_i$ в $\mathrm{mol\,m^{-3}\,s^{-1}}$. Активности и $Q,K_{\mathrm{eq}}$ безразмерны. $\Delta_rG$ измеряется в $\mathrm{J\,mol^{-1}}$ записанной реакции $A\to B$; $G_{\mathrm{ex}},D,\Delta D,W_{\mathrm{end}}$ и разрыв в $\mathrm{J}$; мощность в $\mathrm{W}$. Все численные значения Гиббса используют прямую форму с равновесием по начальному $C_0$. Снижение энергии Гиббса не является теплом или захваченным ATP.

У начальных строк нет предшествующего интервала, поэтому размер шага, приращения, падение, оценка и разрыв равны null; начальные накопленные валовые величины равны нулю. При $A>0,B=0$ значение $Q=0$ допустимо, но движущая сила и мощность равны null. При $A=0,B>0$ частное, движущая сила и мощность равны null. В непустых положительных конечных моментах движущая сила и мощность конечны, а их первая оценка использует конечную мощность текущего конца. У пустой пробы точно нулевые вещество, энергия Гиббса и снижение, но частное, движущая сила, мощность, оценка и разрыв равны null. [Словарь единиц и схемы](../model/inputs/export-schema.json) перечисляет точные строки причин. Никогда не придумывайте малые активности и не считайте null числовым нулём.

Основное окно равно $[0,80000\,\mathrm{s}]$. 401 снимок: $t_j=200j\,\mathrm{s}$ при $j=0,\ldots,400$. Собственные концы шагов, объединение из 1601 момента для кандидата и половинного шага и объединение из 3201 момента для порядка остаются раздельно помеченными в сохранённом CSV проверки и в [заявленном плане эталонов](../model/inputs/benchmark-plan.json). Нелинейные значения Гиббса пересчитываются по интерполированным состояниям; независимый аналитический эталон вычисляется в тот же момент. Критерии точности используют фиксированные заявленные масштабы, а не почти нулевой знаменатель энергетического хвоста.

Семь случаев: forward, reverse, equilibrium, A_only, B_only, empty и partial_final_step. Граничные вспомогательные случаи содержат два полных фактических шага по $100000\,\mathrm{s}$ ($h/\tau=10$). Контроль с частичным последним шагом имеет номинальный шаг $400\,\mathrm{s}$, но фактический укороченный последний шаг $133.33333333332848\,\mathrm{s}$. Вспомогательные случаи дают свидетельство об области определения и учёте, а не о рабочей точности, и не добавляют упражнений. Валовой обмен моделируется, а не измеряется по равновесным концентрациям.

## Канонический необязательный маршрут на Python

Достаточно Python 3 со стандартной библиотекой; этот курс его не требует. Из каталога `courses/energy-constraints/ru/` команда воспроизведения замороженного владельца такова:

```sh
cd ../model
python3 run.py --output fresh-results
```

Используйте новый каталог вывода. Перед любым добровольным воспроизведением прочитайте [prospective-plan.json](../model/prospective-plan.json) и точный [манифест выполнения](../model/execution-manifest.json); не меняйте настройки и критерии. Необязательная команда владельца для проверки сохранённого вывода: `python3 check_saved.py fresh-results` из этого каталога модели. Ни одна из команд не запускалась при подготовке этого учебного кандидата. Анализ готового вывода отличается от этого маршрута независимого выполнения.

[Руководство по модели](../model/README.md) фиксирует исправление предиката повторных нулей и хронологию выполнения. Исправленный провал точности при $400\,\mathrm{s}$, проход при $200\,\mathrm{s}$ и принятие фиксированной политики $100\,\mathrm{s}$ не заменяются ожиданиями. Сохранённая численная верификация не заявляет полевой валидации или валидации на учащихся.
